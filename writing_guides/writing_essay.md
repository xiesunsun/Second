## 1. 专业术语与数学优先原则（关联 `terminology.md`）
- 全文核心术语与中英文固定译名必须严格遵循 [terminology.md](file:///Users/ssunxie/essay/second/tevc-experiments-20261124/writing_guides/terminology.md)，随章节渐进累积、全篇唯一。
- **拒绝自造包装词（Math-First）**：凡是已有清晰数学表达或顶刊通用名称的概念，**一律直接用数学取值或顶刊原词**（如直接写 `$K = \lfloor 0.15p \rfloor$`、`$K = 8$`，严禁自造 `Relaxed Limit`、`Compact Limit`、`Wide-K`、`Tight-K`、`core benchmarks`、`Primary readout` 等词）。
- **去掉冗余防御式数学写法**：在条件天然满足时保持公式最简（如 $p \ge 500$ 时直接写 `$K = \lfloor 0.15p \rfloor$`，不画蛇添足写 `$\max(1, \lfloor 0.15p \rfloor)$`）。
- **全篇同义零混用**：
  - 特征统一用 `features`（$p$），禁用 `attributes`/`variables`/`columns`；
  - 样本统一用 `instances`（$N$），禁用 `samples`/`donors`/`records`；
  - 对比方法统一用 `comparison algorithms` 或 `baselines`，禁用 `competitors`/`counterparts`/`rival methods`；
  - 正文指标名按 `Feng2024` 惯例统一小写（`macro-precision`、`balanced accuracy (BA)`、`macro-F1`、`subset size` / `number of selected features`），百分比差值统一写 `percentage points`（禁用 `points` / `-point lead`）。

## 2. 全篇叙事一致性与核心卖点保护
- **一个统一算法**：全篇只提出一个统一框架 **`SP-PD`**（面向有限预算特征选择的语义先验引导进化搜索与配对交付框架），严禁另造 `SP-PD-Num` 或 `无先验模式` 等割裂称呼。
- **保护论文核心亮点**：大语言模型离线语义先验与统一配对交付是论文的核心卖点。在纯数值高维基准节（IV-B）**严禁反复强调“无领域语义 / 未用大模型”**以免自我削弱亮点；仅在设置节（IV-A）客观交代一次“有可读特征描述时由单次离线查询引入语义先验，否则由数据驱动排序启动”，其余章节直接正面展示统一框架的性能。
- **零工程黑话**：严禁出现内部审计或实验日志词汇（`轨道`、`零历史`、`独立未见数据集`、`Suite I/II`、`里程碑值`、`对数加权积分`、`Earlier-6`、`New-6`、`Wrong`、`工单` 等）；严禁报告与实验结论无关的服务器内存配置（如 `62 GB RAM`）。

## 3. 段落结构、句长与论证逻辑
- **短节禁堆砌小标题**：3–4 段以内的小节严禁堆砌多余的行内编号小标题（`1) ... 2) ...`）、`\subsubsection` 或项目符号清单，应通过清晰的主题句自然衔接成连贯学术段落。
- **禁止“按表报流水账”**：严禁写成“第 1 段念 Table II、第 2 段念 Table III、第 3 段念 Fig. 1”；必须按**科学问题与对比算法家族**分层推进，形成 **“核心事实 → 对手为何弱 → 我方机理为何强”** 的三步闭环。
- **硬句长红线**：英文单句原则上 **≤ 38 词**（建议均值 20–30 词，长短错落）；中文单句不堆叠 3 个以上长分句。
- **删句测试（Deletion Test）**：逐句自问“删掉这句话是否损失实质技术信息或逻辑前提？”，凡空报幕句（如 `Fig. 1(b) illustrates why...`、`Table III evaluates...`）和无增量修饰语一律删除。
- **篇幅控制**：Section IV 开篇导语 ≤ 70 英文词；Section IV-A 约 260–320 词；单个结果分析小节（如 IV-B）约 300–380 词。

## 4. 括号克制与禁止正文复读表格
- **Chart/Table-First**：表格或矢量图已清晰展示的明细数字，正文**严禁再用括号逐个抄写复读**。
- **括号硬约束**：正文括号仅用于极简缩写（`(BA)`、`(NC)`）、图子标号（`Fig. 1(b)`）或极简统计值（`($p < 1.3 \times 10^{-9}$)`）；**严禁把算法列举名单、整句解释或成串表格数值塞进括号里**（列举算法统一用 `namely ...`、`including ...` 融入主句；单个结果小节非图号括号原则上 **≤ 2–3 处**）。
- **100% 数据可追溯**：正文提及的任何单个数据集的具体指标或特征数，必须在主表、主图或附录表（如 `Appendix Table S-II`）中有据可查，绝不留悬空数字。

## 5. 统计检验与学术语域
- **统计呈现透明克制**：
  - 跨数据集独立组比较不借用单数据集多次运行的 `+/=/-` 符号或杂乱的 `†`；
  - 逐数据集主表（如 Table II）底行直接给出透明精确的 `Mean`、`Mean #Feat`、`Friedman Rank` 与双侧 Wilcoxon **`$p$-value`**；
  - 多指标汇总表（如 Table III）仅用最通用克制的 `*`（配合 `\rlap{\textsuperscript{*}}` 保持小数点对齐）标示 Wilcoxon $p < 0.05$，**仅在表注一行说明，正文绝不复述符号定义**。
- **冷静客观语气**：严禁使用夸张、推销或防御性词汇（`dramatically`, `crushes`, `superiority`, `overwhelming`, `without cherry-picking`, `crucially`, `rigorously`, `comprehensive`）；客观承认个别数据集的局限，靠整体均值、平均秩、显著性检验与特征压缩建立说服力。

## 6. 格式、字体与标点规范
- 正文段落 **0 处 `\textbf{}`**（加粗仅用于表格每行最优值）、**0 处 `\texttt{}`**（算法名与数据集名一律正体 Roman）、**0 处 `---`**。
- 引用与图/表编号前加不换行空格 `~`；数学运算符保持标准间距（`$K = 8$`、`$B = 1{,}000$`）；中文稿使用全角中文标点、中英文数字间留标准空格。
- 所有对比算法在首次出现时必须给出原始文献引用，不留悬空方法名。

## 7. IEEE TEVC 表格制作硬标准（Tables）
1. **概念边界纯净**：
   - 数据集属性表（Table I）只列数据集固有属性（`Dataset | #Features | #Instances | #Classes | Min/Max (%)`），按 `#Features` 单调降序排列；**严禁混入实验超参数（如 $K$、$B$）或表中未定义的符号**。
   - **严禁把实验协议散文切碎塞进窄列汇总表**（协议在 IV-A 用简洁正文交代，完整对比算法超参数分流至附录 `Table S-I`，参考 `Feng2024` 与 `Li2023`）。
2. **表题单行精炼 & 分组无重复**：
   - 主副表表题力争 **6–10 英文词、单行排版**，表题与单元格末尾**不加句号**。
   - 分组行简洁加粗（如 `High-Dimensional Benchmarks`、`Clinical Datasets`），并在组名下加 `\addlinespace[2pt]`；**严禁出现 `(24 Datasets)`、`(12 Binary Datasets)` 等冗余括注**。
   - 表格与正文中的数据集名、术语不草率截断（写 `DLBCL / Lymphoma`，不写 `DLBCL / lymph.`）。
3. **结果表正交规范**：
   - 本文方法 **`SP-PD` 固定居最右列**（行排表则居最底行并以 `\midrule` 分隔），每行最优值 `\textbf{}` 标粗。
   - 同列小数位数严格一致（百分比 2 位 `xx.xx`，特征数 1 位 `xx.x`，秩 2 位 `x.xx`，精确 $p$ 值 3 位 `0.xxx`）；所有星号上标使用 `\rlap{\textsuperscript{*}}` 保证小数点逐列垂直对齐。
   - 同类汇总行名全篇统一（`Mean`、`Mean #Feat`、`Friedman Rank`、`$p$-value`），**主表之间职责正交、严禁整行/整列重复同一结果**。
4. **就近排版**：主表通过合理浮动（`table*[!t]` / `table*[!b]` + `stfloats`）排在引用页或其紧邻页，杜绝纯浮动页或堆叠至文末；附录表紧凑合排于独立附录页。

## 8. IEEE TEVC 矢量图硬标准（Figures）
1. **纯矢量与字体一致**：所有图在远程服务器 `lab` 用 `matplotlib` 导出纯矢量 PDF（`pdf.fonttype=42`），采用与 `IEEEtran` 一致的衬线字体（`STIXGeneral` + `mathtext.fontset='stix'`）。
2. **真实物理尺寸与可读性**：单栏图按 `3.45 in` 宽设计，通栏图按 `7.10 in` 宽设计；最终缩放后刻度、轴标与图例等效不小于 `7.5–8 pt`。
3. **黑白可读 & 信息直击论点**：采用色盲安全低饱和配色（Okabe–Ito 系），`SP-PD` 用醒目深红粗实线 + 实心圆突出，对比算法同时以不同线型和空心标记区分；**优先选择最能直观体现算法机理差异的指标绘制**（如 Fig. 1(c) 以 BA 曲线直观展现 SP-PD 单调上升 vs. MEL 过拟合回落）。
4. **单行极简图注 & 无遮挡**：去掉顶/右边框，浅灰虚线网格，共享图例置于顶部空白区，**绝不遮挡曲线**；子图标题直接用清晰数学条件（如 `$K = \lfloor 0.15p \rfloor$`、`$K = 8$`），图注压缩至 **≤ 20 词（1–1.5 行）**，不重复子图标题。

## 9. 方法章（Section III: Proposed Method）专项撰写纪律
为确保后续撰写 **Section III（所提方法 SP-PD）** 与 Section IV 无缝衔接并达到 *IEEE TEVC* 水准，必须遵守以下额外纪律：
1. **全局符号唯一锁定**：在 Section III 正式定义且仅定义一次全部核心符号（$p, N, C, B, K, R, \lambda$ 及掩码、先验排序、重复配对目标等），与 Section IV 及附录表 `Table S-I` 保持 100% 字母一致；每个公式中的所有变量必须在紧邻 `where ...` 中逐一界定，无悬空符号。
2. **总–分结构清晰（对标 `Li2023` & `Feng2024` Sec. III）**：
   - 先用 1 段 + 1 张高洁净度**整体框架矢量图**交代 SP-PD 的端到端数据流（统一说明：具备可读特征描述时由单次离线 LLM 查询生成语义先验，否则由数据驱动排序启动，随后进入统一的有限预算进化搜索与配对交付）；
   - 再按算法执行顺序分小节展开核心组件，每节坚持 **“直觉动机（1–2 句）→ 严谨数学定义 → 机理作用”**，**严禁给普通步骤起花哨自造缩写或营销包装词**；
   - 给出标准的 `IEEEtran` 伪代码（`Algorithm 1`），输入、输出、预算消耗计步 $B$ 与正文公式严格对应；
   - 末尾单列简洁的**复杂度分析**（区分时间复杂度与 LLM 查询复杂度：明确指出离线语义先验仅需 $O(1)$ 次查询，不随特征维数 $p$ 线性增长）。
3. **与实验章互锁**：Section III 中提出并强调的每一个核心设计（如单次离线先验初始化、结构化搜索、重复配对先验正则交付 $R, \lambda$），必须在 Section IV 的主对比（IV-B/IV-C）、效率分析（IV-D）或消融敏感性（IV-E）中有明确的一一对应验证，杜绝“方法讲了实验没测”或“实验测了方法没提”。

## 10. 审稿自检循环协议（12 项全检，未全过严禁交付）
每次初稿完成后、交付人类审阅前必须逐条执行以下 12 项检查；**任何一项不通过，必须原地重写并重新编译核验，直到 12 项全过**：
1. **对标与叙事检查**：是否对标了顶刊结构与用词？是否保护了统一框架 `SP-PD` 与核心卖点，无“无语义/无大模型”的自我削弱表述？
2. **术语与数学纯净检查**：逐词核对 `terminology.md`，零自造包装词（`Relaxed/Compact Limit`、`core`、`Primary readout`）、零冗余 `\max(1, \cdot)`、零工程黑话。
3. **结构与删句测试**：短节无多余行内小标题，无按表流水账，无空报幕句，无无增量修饰语。
4. **句长与篇幅检查**：英文单句 ≤ 38 词，各小节篇幅紧实克制。
5. **括号与去重检查**：单个结果小节非图号括号 ≤ 2–3 处，正文不复读表格明细，引用的每个数值在主/附录表 100% 可追溯。
6. **统计与语气检查**：透明呈现精确 `p-value` 或克制 `*`，正文不背诵符号定义，零夸张/推销词。
7. **格式与字体检查**：正文 0 处 `\textbf`、0 处 `\texttt`、0 处 `---`，表题与单元格末尾无句号，数据集名不截断。
8. **表格美学与正交检查**：数据集表概念纯净；结果表 `SP-PD` 居最右列、最优值加粗、`\rlap` 对齐小数点、单行表题、表间零重复、无纯浮动页。
9. **矢量图质量检查**：`lab` 导出的 STIX 衬线矢量 PDF，按 IEEE 物理宽度绘制，黑白可辨，数学子图标题清晰，图注 ≤ 20 词且不重复标题，无遮挡。
10. **方法–实验符号互锁检查**：全部数学符号与 Section III / IV / Appendix 完全一致，无未定义或重名符号。
11. **逐页视觉审查**：将编译 PDF 全部页面转为 `page_*.png` 并逐页目视检查，确保达到 *IEEE TEVC* 印刷级观感。
12. **编译洁净度检查**：`pdflatex` + `bibtex` 实现 **0 Warning / 0 Error / 0 Overfull / 0 Underfull**。
